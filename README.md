Быстрая диагностика без управления:

```bash
cd /home/jetson/verter-robot
bash tools/verter status
bash tools/verter health
```

`status` показывает процессы и режим, `health` — готовность входов SLAM/Nav2. После автозапуска работают hardware, voice, web и отдельные службы NATS/BMS/камеры/обработки препятствий; режим supervisor — `idle`. SLAM и Nav2 запускаются оператором отдельно.

Чистая установка всей системы пока не прошла отдельную приёмку. Установщики, ручные этапы и ограничения описаны в INSTALL.md. Реальные команды движения, остановки, навигационные цели и прошивка устройств требуют согласования владельца.
