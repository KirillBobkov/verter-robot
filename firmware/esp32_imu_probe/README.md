# Диагностика IMU: чтение регистров

Отдельная прошивка ESP32: SDA21/SCL22, I2C 100 kHz с таймаутом 50 ms, USB 115200. Без ROS, управления приводом, BLE и опроса УЗ. Не изменяет конфигурацию датчиков, не сбрасывает их и не запускает калибровку. Запись I2C используется только для выбора читаемого регистра.

Проверяет ID 0xFA на адресах 0x18/0x19 и ID 0x0F на 0x68/0x69. NACK отсутствующего альтернативного адреса ожидаем. При неоднозначности или неизвестном ID измерения этого чипа не декодируются.

Команды: STATUS, DUMP, SAMPLE, START (10 опросов/с), STOP. При старте поток выключен. Читаются диапазоны, полоса, режим питания, регистры компенсации. Выводятся сырые значения и SI по прочитанному диапазону, свежесть акселерометра, ошибки и короткие чтения. При ошибке старые значения не выдаются вместо новых. Чтение может снимать флаги свежести; новизна гироскопа отдельным interrupt не проверяется.

BMA cal_rdy: бит4 регистра0x36. BMG fast_offset_en: бит3 регистра0x32, сбрасывается после завершения. Состояние idle не доказывает успешную калибровку в прошлом. Источник BMG: Bosch BMG160 datasheet rev1.2, раздел4.6.2: https://www.mouser.com/datasheet/2/783/BST-BMG160-DS000-09-1221199.pdf . BMA сверена с библиотекой проекта iarduino_Position_BMX055_BMA.h. Декодирование допустимо только при совпадении прочитанного ID.

Сборка: pio run. tests/test_decode.cpp проверяет signed12/16, крайние значения, масштабы, 1g и полярность флагов. Масштаб гироскопа номинальный full-scale/32768, не метрологическая калибровка.

Для согласованного аппаратного теста: проверить владельцев порта sensors и способ остановки агента/EKF; снять полный backup flash именно sensors, не ctrl; временно прошить probe; записать BOOT/DUMP и 60 секунд START; восстановить полный flash с verify_flash и согласованно вернуть процессы. Перед остановкой учитывать обработчики завершения launch. Во время теста IMU и все УЗ этой ESP32 недоступны. Движение и навигация исключаются. Если датчик спит, отсутствие измерений не доказывает неисправность: probe его не будит.

Загрузка на ESP32 требует отдельного согласования.
