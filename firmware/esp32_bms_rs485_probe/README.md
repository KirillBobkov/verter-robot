# Проверка JK BMS через UART–RS485

Отдельная диагностическая прошивка ESP32. ROS, BLE, управление приводом и запись
настроек BMS отсутствуют. Для штатной телеметрии используется BLE-сервис Jetson.

UART2: по умолчанию TX=GPIO17, RX=GPIO16, 115200 бод, 8N1; USB-консоль — 115200.
На старте работает только приём, автоматических запросов BMS нет. Программа
не управляет DE/RE: для передачи нужен трансивер с подходящим управлением направлением.
Назначение GPIO не подтверждает распиновку разъёма BMS.

| Команда USB-консоли | Действие |
|---|---|
| `STATUS` | Счётчик принятых байтов и готовность UART |
| `PINS 17 16` | TX=17, RX=16; передатчик остаётся отключённым до READ |
| `PINS 16 17` | TX=16, RX=17 |
| `BAUD <скорость>` | Меняет скорость без запроса BMS |
| `READ` | Один фиксированный JK legacy 4E57 READ_ALL; после передачи TX становится входом |

Допустимые скорости: 1200, 2400, 4800, 9600, 19200, 38400, 57600, 115200,
230400, 460800. Вывод `RX <millis> <hex>` содержит принятые порции; STATUS
также печатается каждые 5 секунд. Эхо запроса не является ответом BMS.
Совместимость legacy-протокола с конкретным устройством требует проверки.

Сборка и ограничения загрузки — [общая инструкция](../README.md). Перед загрузкой
нужны согласование, идентификация платы и способ восстановления штатного flash.
Не запускать аппаратный тест вместо unit-тестов. Логи BMS могут содержать секреты.
