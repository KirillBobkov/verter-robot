# IMU initialization probe
Separate temporary firmware. RUN100/RUN400 repeat A/G/M begin and production range/bandwidth settings, read back registers, wait10s, record before/after calibration, estimate gyro bias from2048 reads, observe500 corrected samples. No ROS or motor control. Calibration changes volatile sensor offsets; no NVM writes. BMA waits for ready bit0x10 to set; BMG waits for busy bit0x08 to clear. Errors abort that run. Actual Wire clock is printed because library begin can override it. Library writeByte is traced, which changes timing; success does not prove the original uninstrumented firmware is reliable. Restore full original sensor flash after testing. Build with `pio run`; flashing and calibration require explicit authorization and verified board identification.
