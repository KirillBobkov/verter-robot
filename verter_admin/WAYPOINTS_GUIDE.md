# 📍 Руководство по именованным точкам (Waypoints)

## Что это?

**Waypoints (именованные точки)** - это сохранённые места на карте, к которым робот может автоматически ехать.

Например:
- "Кабинет директора"
- "Ресепшен"
- "Туалет"
- "Кухня"
- "Зарядная станция"

---

## 🎯 Для кого это руководство?

Для **любого пользователя робота** - не нужно быть программистом!

Всё что нужно уметь:
- Управлять роботом вручную (джойстик или клавиатура)
- Запускать простые команды

---

## 🚀 Быстрый старт

### 1. Сохранить место

```bash
# Отвезите робота в нужное место вручную
# Затем выполните:
./save_waypoint.sh "Кабинет директора"
```

### 2. Отправить робота к месту

```bash
./goto_waypoint.sh "Кабинет директора"
```

### 3. Посмотреть все сохранённые места

```bash
./list_waypoints.sh
```

## 📖 Подробная инструкция

### Шаг 1: Запустить робота

```bash
# На реальном роботе
ros2 launch verter_admin real_robot_navigation.launch.py

# Или в симуляции
ros2 launch verter_admin autonomous_mapping.launch.py
```

**Важно:** Убедитесь, что карта загружена и робот локализован!

---

### Шаг 2: Создать первую точку

#### Вариант A: Отвезти робота вручную

```bash
# 1. Запустить телеоператорское управление
ros2 run verter_admin teleop_keyboard

# 2. Управляя клавишами, отвезите робота в нужное место
#    Например, к входу в кабинет директора

# 3. Остановите робота РОВНО там, где хотите

# 4. В другом терминале сохраните позицию
cd ~/verter/verter-robot/verter_admin
./save_waypoint.sh "Кабинет директора" "Второй этаж, справа"
```

#### Вариант B: Кликнуть в RViz (альтернатива)

*Примечание: В текущей версии используйте Вариант A*

---

### Шаг 3: Использовать сохранённые точки

```bash
# Показать все точки
./list_waypoints.sh

# Отправить робота к точке
./goto_waypoint.sh "Кабинет директора"
```

**Робот автоматически:**
1. Построит маршрут
2. Объедет препятствия
3. Приедет в точку с правильной ориентацией

---

## 📚 Все команды

### 1. Сохранить текущую позицию

```bash
./save_waypoint.sh "Название места"

# С описанием:
./save_waypoint.sh "Ресепшен" "Главный вход, у стойки"
```

**Что происходит:**
- Робот определяет свою текущую позицию
- Сохраняет координаты (x, y) и ориентацию (yaw)
- Добавляет в файл `waypoints.yaml`

---

### 2. Отправить робота к точке

```bash
./goto_waypoint.sh "Название места"

# Примеры:
./goto_waypoint.sh "Кабинет директора"
./goto_waypoint.sh "Ресепшен"
./goto_waypoint.sh "Зарядная станция"
```

**Что происходит:**
- Nav2 строит маршрут до точки
- Робот едет автоматически
- Объезжает препятствия
- Прибывает к цели

---

### 3. Посмотреть все точки

```bash
./list_waypoints.sh
```

**Вывод:**
```

==================================================

   Координаты: x=5.20, y=3.10

   Координаты: x=0.50, y=1.20
   Ориентация: 0.00 рад (0.0°)
   Описание: Главный вход

Всего точек: 2
```

---

### 4. Удалить точку

```bash
./delete_waypoint.sh "Название места"

# Пример:
./delete_waypoint.sh "Старый офис"
```

---

### 5. Обновить точку

```bash
# Просто сохраните снова с тем же именем
./save_waypoint.sh "Кабинет директора"

# Координаты обновятся
```

## 💡 Полезные советы

### 1. Точная ориентация важна!

Когда сохраняете точку, убедитесь, что робот смотрит в нужную сторону:
- Для двери - лицом к двери
- Для стола - лицом к столу
- Для зарядки - в позицию для подключения

### 2. Используйте понятные названия

**Хорошие примеры:**
- ✅ "Кабинет директора"
- ✅ "Ресепшен - главный вход"
- ✅ "Зарядная станция - склад"

**Плохие примеры:**
- ❌ "Точка 1"
- ❌ "wp_001"
- ❌ "Там где обычно"

### 3. Добавляйте описания

```bash
./save_waypoint.sh "Кухня" "Третий этаж, рядом с лифтом"
```

Это поможет другим пользователям понять, где находится место!

### 4. Сохраняйте важные точки

**Обязательно создайте:**
- Стартовую позицию (где робот обычно начинает работу)
- Зарядную станцию
- Безопасное место для парковки

### 5. Тестируйте новые точки

После создания точки, сразу протестируйте:
```bash
./goto_waypoint.sh "Новая точка"
```

Убедитесь, что робот приезжает туда правильно!

## 🔧 Расширенное использование

### Создание маршрута из нескольких точек

```bash
# Скрипт для обхода нескольких точек
./goto_waypoint.sh "Ресепшен"
# Дождитесь прибытия...
./goto_waypoint.sh "Кабинет 1"
# Дождитесь прибытия...
./goto_waypoint.sh "Кабинет 2"
# И так далее...
```

### Экспорт/импорт точек

```bash
# Создать резервную копию
cp waypoints.yaml waypoints_backup.yaml

# Перенести на другого робота
scp waypoints.yaml robot2:~/verter/verter-robot/verter_admin/
```

### Ручное редактирование (для продвинутых)

```bash
# Открыть файл с точками
nano waypoints.yaml
```

**Формат:**
```yaml
waypoints:
  - name: "Кабинет директора"
    x: 5.2      # метры от origin карты
    y: 3.1      # метры от origin карты
    yaw: 1.57   # радианы (0 = восток, 1.57 = север, 3.14 = запад)
    description: "Второй этаж"
```

## ⚠️ Troubleshooting

### Проблема: "Не удалось получить позицию робота"

**Решение:**
```bash
# 1. Проверьте, что SLAM/локализация работает
ros2 topic hz /map

# 2. Проверьте TF tree
ros2 run tf2_tools view_frames
# Откройте frames.pdf и убедитесь, что map -> base_link существует

# 3. Убедитесь, что робот локализован (установите 2D Pose Estimate в RViz)
```

---

### Проблема: "Точка не найдена"

**Решение:**
```bash
# Посмотрите список всех точек
./list_waypoints.sh

# Проверьте точное написание (с учётом регистра и пробелов!)
./goto_waypoint.sh "Кабинет Директора"  # ❌ Неправильно
./goto_waypoint.sh "Кабинет директора"  # ✅ Правильно
```

---

### Проблема: "Робот не может добраться до точки"

**Возможные причины:**
1. Точка находится в недоступном месте (за стеной, в углу)
2. На пути появились препятствия
3. Карта устарела

**Решение:**
1. Проверьте маршрут в RViz (отобразите `/plan`)
2. Попробуйте отправить робота поближе
3. Обновите карту, если планировка изменилась
4. Пересохраните точку в более доступном месте

---

### Проблема: "Робот приезжает, но не в ту сторону смотрит"

**Решение:**
```bash
# 1. Отвезите робота вручную
ros2 run verter_admin teleop_keyboard

# 2. Разверните его ТОЧНО в нужную сторону

# 3. Пересохраните точку
./save_waypoint.sh "Кабинет директора"
```

## 🎓 Примеры использования

### Пример 1: Робот-курьер в офисе

```bash
# 1. Создать точки для всех кабинетов
./save_waypoint.sh "Кабинет 101"
./save_waypoint.sh "Кабинет 102"
./save_waypoint.sh "Кабинет 103"
./save_waypoint.sh "Ресепшен"

# 2. Доставка документов
./goto_waypoint.sh "Кабинет 102"
# Робот доставляет документы...
./goto_waypoint.sh "Ресепшен"
# Робот возвращается
```

### Пример 2: Робот-уборщик

```bash
# Создать точки для зон уборки
./save_waypoint.sh "Коридор - начало"
./save_waypoint.sh "Коридор - середина"
./save_waypoint.sh "Коридор - конец"
./save_waypoint.sh "Зарядка"

# Маршрут уборки
./goto_waypoint.sh "Коридор - начало"
./goto_waypoint.sh "Коридор - середина"
./goto_waypoint.sh "Коридор - конец"
./goto_waypoint.sh "Зарядка"
```

### Пример 3: Робот-экскурсовод

```bash
# Создать точки для экскурсии
./save_waypoint.sh "Вход - точка старта"
./save_waypoint.sh "Экспонат 1 - Древний артефакт"
./save_waypoint.sh "Экспонат 2 - Картина"
./save_waypoint.sh "Экспонат 3 - Скульптура"
./save_waypoint.sh "Выход"

# Провести экскурсию
for place in "Вход" "Экспонат 1" "Экспонат 2" "Экспонат 3" "Выход"; do
    ./goto_waypoint.sh "$place"
    # Пауза для рассказа...
    sleep 30
done
```
