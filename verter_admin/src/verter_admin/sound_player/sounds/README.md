# Звуковые файлы для Verter Admin

Эта папка содержит звуковые файлы для воспроизведения через sound_player_node.

## Поддерживаемые форматы
- .wav (рекомендуется - быстрое воспроизведение)
- .mp3 (медленнее - требует конвертации)
- .ogg (медленнее - требует конвертации)

## Использование

Отправьте сообщение в топик `/play` с именем файла:

```bash
# Воспроизвести wav файл (БЫСТРО!)
ros2 topic pub /play std_msgs/String "data: 'trigger'"

# Воспроизвести файл с расширением
ros2 topic pub /play std_msgs/String "data: 'sound.wav'"
ros2 topic pub /play std_msgs/String "data: 'music.mp3'"

# Специальные команды
ros2 topic pub /play std_msgs/String "data: 'joke'"  # Воспроизвести шутку
ros2 topic pub /play std_msgs/String "data: 'stop_sound'"  # Остановить воспроизведение
```


## Рекомендации по производительности

- **Используйте .wav файлы** для максимальной скорости воспроизведения
- **Избегайте .mp3** для коротких звуков (триггеры, уведомления)
- **Конвертируйте** существующие mp3 в wav для ускорения

## Шутки

Для воспроизведения шуток используйте команду `joke`. Нода автоматически чередует между файлами:
- joke1.wav
- joke2.wav  
- joke3.wav
