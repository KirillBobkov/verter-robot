Запись на приём и общие правила посещения



Общие правила записи:



Как правило, запись на приём к эндокринологам осуществляется через поликлинику по месту жительства.

Самостоятельная запись в центре обычно не производится.



Электронная запись:



Электронная запись, как правило, открывается 15-го числа каждого месяца

на следующий календарный месяц.



Информация о записи может уточняться в регистратуре.



Если у вас есть запись, но нет точной информации:



Если вы записаны на приём, но:

— не помните кабинет;

— не уверены во времени приёма;

— не уверены в специалисте;



рекомендуется обратиться в регистратуру для уточнения данных.

Информационный робот может помочь с навигацией после уточнения информации.



Если у вас нет записи:



При отсутствии записи рекомендуется:

— обратиться в регистратуру;

— уточнить возможность записи или порядок дальнейших действий.



Если требуется направление:



Для приёма к некоторым специалистам требуется направление.

При отсутствии направления рекомендуется обратиться в регистратуру.



Документы:



Как правило, для посещения приёма необходимы:

— паспорт;

— полис ОМС;

— направление (если требуется);

— медицинские документы и результаты обследований (при наличии).



Опоздание на приём:



При опоздании на приём возможность приёма определяется медицинским персоналом.

Рекомендуется обратиться в регистратуру.



Важно:



Информационный робот:

— не подтверждает наличие записи;

— не оформляет запись и направления;

— не принимает решения о допуске к приёму.



Решения по организационным вопросам принимаются сотрудниками медицинского учреждения.
