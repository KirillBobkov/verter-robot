# Все возможные кейсы работы системы распознавания речи

## **КЕЙС 1: Простые триггеры**

### **1.1 Только триггер**
```
👤 "Робот"
🤖 *бип* (LISTENING_FOR_TRIGGER → CAPTURING_COMMAND)
👤 "включи свет"
🤖 "Свет включен" (CAPTURING_COMMAND → DIALOG_MODE → PAUSED → DIALOG_MODE)
```

### **1.2 Триггер + команда AI**
```
👤 "Робот включи музыку"
🤖 *бип* (LISTENING_FOR_TRIGGER → DIALOG_MODE → PAUSED)
🤖 "Музыка включена" (PAUSED → DIALOG_MODE)
```

### **1.3 Триггер + команда шасси**
```
👤 "Робот вперед"
🤖 *бип* *движется вперед* (LISTENING_FOR_TRIGGER → DIALOG_MODE)
```

### **1.4 Неправильный триггер**
```
👤 "Привет"
🤖 *молчит* (остается в LISTENING_FOR_TRIGGER)
```

### **1.5 Очень длинный триггер (>100 символов)**
```
👤 "Робот это очень длинная фраза которая превышает максимальную длину для триггера..."
🤖 *игнорирует* (превышен MAX_TEXT_LENGTH_FOR_TRIGGER)
```

## **Состояния системы:**

1. **🔍 LISTENING_FOR_TRIGGER** - Ждем триггерное слово
2. **⏳ CAPTURING_COMMAND** - Ждем команду после триггера  
3. **💬 DIALOG_MODE** - Режим диалога
4. **⏸️ PAUSED** - Пауза (робот говорит)

## **Приоритеты команд:**

1. **Стоп-слова** (высший приоритет) - "хватит", "спасибо", "пока", "досвидания", "до свидания", "завершить", "закончить", "конец", "всё", "все", "достаточно"
2. **Команды шасси** (средний приоритет) - "вперед", "назад", "влево", "вправо", "стоп", "остановись"
3. **Команды для AI** (низший приоритет) - все остальные фразы

## **Таймеры:**

- **Тайм-аут команды:** 10 секунд (после триггера)
- **Тайм-аут диалога:** 30 секунд (в режиме диалога)

## **Триггерные слова:**

'робот', 'робат', 'бертом', 'верстах', 'вертэр', 'вертер', 'ветер', 'ертер', 'верте', 'вектор', 'ветера', 'мерсер', 'вертера', 'вердер', 'лестер'

## **Команды шасси:**

- 'назад' → 'CHASSIS:BACK'
- 'стоп', 'остановись' → 'CHASSIS:STOP'
- 'влево', 'налево' → 'CHASSIS:LEFT'
- 'вправо', 'направо' → 'CHASSIS:RIGHT'
- 'вперед', 'прямо' → 'CHASSIS:FRONT'

## **КЕЙС 11: TTS и управление микрофоном**

### **11.1 Базовый цикл TTS**
```
👤 "Робот включи свет"
🤖 *бип* (DIALOG_MODE → PAUSED)
🔇 *Микрофон отключается* (set_recognition_active=False)
🤖 "Свет включен" *говорит через Piper*
⏰ *Задержка 0.7 сек для затухания*
🎤 *Микрофон включается* (set_recognition_active=True, PAUSED → DIALOG_MODE)
```

### **11.2 Конкуренция запросов TTS**
```
👤 "Робот скажи что-то длинное"
🤖 *бип* *начинает говорить длинный текст*
🤖 *новый запрос TTS приходит*
🤖 *_pending_text заменяется новым текстом*
🤖 *после окончания первого - говорит второй*
```

### **11.3 Ошибка синтеза речи**
```
👤 "Робот скажи что-то"
🤖 *бип* (PAUSED)
🔇 *Микрофон отключается*
❌ *Ошибка Piper синтеза*
🎤 *Микрофон включается обратно* (восстановление)
```

### **11.4 Ошибка aplay процесса**
```
👤 "Робот говори"
🤖 *бип* *синтез успешен*
❌ *aplay завершился с ошибкой*
🤖 *Логирует ошибку aplay*
🎤 *Микрофон включается обратно*
```

## **КЕЙС 15: DOA (Direction of Arrival)**

### **15.1 DOA углы и команды головы**
```
🎯 *Говорят справа (300°)*
🤖 *HEAD:RIGHT* (270-360°)

🎯 *Говорят слева (200°)*  
🤖 *HEAD:LEFT* (150-270°)

🎯 *Говорят спереди (90°)*
🤖 *HEAD:CENTER* (10-150°)
```

### **15.2 DOA debounce (предотвращение повторов)**
```
🎯 *DOA: 300° → HEAD:RIGHT*
🤖 *Отправляет HEAD:RIGHT*
🎯 *DOA: 305° → HEAD:RIGHT*
🤖 *Пропускает (last_eye_command == HEAD:RIGHT)*
🎯 *DOA: 100° → HEAD:CENTER*
🤖 *Отправляет HEAD:CENTER* (команда изменилась)
```

### **15.3 DOA отключен (нет ReSpeaker)**
```
🔧 *Запуск без ReSpeaker устройства*
🤖 *doa_enabled = False*
⚠️ *DOA команды не отправляются*
```

### **15.4 Ошибка DOA**
```
🎯 *Попытка получить DOA угол*
❌ *Ошибка USB соединения*
🤖 *Логирует ошибку DOA*
🤖 *Продолжает работу без DOA*
```

🔧 *Внешняя команда: end_dialog*
🤖 *AI удаляет thread*
🤖 *dialog_active = False*
```

## **КЕЙС 20: Edge Cases и ошибки**

### **20.1 Очень длинный ответ AI (>200 символов)**
```
👤 "Робот расскажи подробно"
🤖 *AI возвращает 500+ символов*
🤖 *TTS синтезирует полностью*
🤖 *Очень долгое воспроизведение*
```

### **20.2 Специальные символы в командах**
```
👤 "Робот ! @ # $ % ^ & *"
🤖 *Распознано как команда для AI*
🤖 *Обработка без ошибок*
```

### **20.3 Пустая команда**
```
👤 "Робот"
🤖 *бип* (CAPTURING_COMMAND)
👤 "" *пустая строка*
🤖 *игнорирует* (не проходит валидацию)
```

### **20.4 Одновременные команды разных типов**
```
👤 "Робот вперед стоп спасибо"
🤖 *Приоритет 1: спасибо (стоп-слово)*
🤖 *"Рад был помочь"* (игнорирует вперед и стоп)
```

### **20.5 Быстрые повторяющиеся триггеры**
```
