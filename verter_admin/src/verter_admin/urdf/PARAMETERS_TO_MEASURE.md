## 📦 1. Размеры корпуса (base_link)

### Что измерить:
- [ ] **Длина** (вперед-назад): ___ см
- [ ] **Ширина** (влево-вправо): ___ см
- [ ] **Высота**: ___ см

### Где в URDF:
```xml
<!-- Строка ~73 в verter_robot.urdf -->
<geometry>
  <box size="0.30 0.20 0.10"/>
  <!--      ^^^^  ^^^^  ^^^^
         Длина Ширина Высота (в метрах) -->
</geometry>
```

### Текущие значения (примерные):
- Длина: 0.30 м (30 см)
- Ширина: 0.20 м (20 см)
- Высота: 0.10 м (10 см)

### Как измерить:
1. Линейкой/рулеткой измерить корпус робота
2. Длина = от переднего края до заднего края
3. Ширина = от левого края до правого края
4. Высота = от земли до верха корпуса (без учета антенн/датчиков)

## ⚙️ 2. Колеса

### Что измерить:
- [ ] **Диаметр колеса**: ___ см
- [ ] **Ширина колеса**: ___ см
- [ ] **Расстояние между колесами** (wheelbase): ___ см
- [ ] **Позиция колес относительно центра корпуса**: ___ см

### Где в URDF:
```xml
<!-- Строки ~122, ~166 в verter_robot.urdf -->

<!-- Размеры колеса -->
<geometry>
  <cylinder radius="0.065" length="0.03"/>
  <!--       ^^^^^^         ^^^^^^
           Радиус        Ширина (в метрах) -->
</geometry>

<!-- Позиция левого колеса -->
<origin xyz="-0.05 0.11 0" rpy="0 0 0"/>
<!--         ^^^^^  ^^^^
           X      Y (расстояние от центра) -->
```

### Текущие значения (примерные):
- Радиус колеса: 0.065 м (6.5 см, диаметр 13 см)
- Ширина колеса: 0.03 м (3 см)
- Позиция X: -0.05 м (5 см назад от центра)
- Позиция Y: ±0.11 м (11 см от центра влево/вправо)

### Как измерить:
1. **Диаметр колеса**: Измерить от края до края колеса. Радиус = Диаметр / 2
2. **Ширина**: Толщина протектора колеса
3. **Wheelbase**: Расстояние между центрами левого и правого колес
4. **Позиция X**: Насколько колеса смещены назад от центра робота
5. **Позиция Y**: Wheelbase / 2

## 🎡 3. Опорные колеса (Caster Wheels)

### Что измерить:
- [ ] **Диаметр опорного колеса**: ___ см
- [ ] **Позиция относительно центра**: ___ см
- [ ] **Количество опорных колес**: ___ шт

### Где в URDF:
```xml
<!-- Строка ~199 в verter_robot.urdf -->
<geometry>
  <sphere radius="0.02"/>
  <!--            ^^^^
                Радиус -->
</geometry>

<origin xyz="0.10 0 -0.045" rpy="0 0 0"/>
<!--         ^^^^      ^^^^^
           X (вперед)  Z (высота) -->
```

### Текущие значения (примерные):
- Радиус: 0.02 м (2 см, диаметр 4 см)
- Позиция X: 0.10 м (10 см вперед от центра)
- Позиция Z: -0.045 м (ниже base_link)

### Как измерить:
1. **Диаметр**: Измерить опорное колесо. Радиус = Диаметр / 2
2. **Позиция X**: Расстояние от центра робота до опорного колеса
3. **Позиция Z**: Обычно = -(высота основных колес - радиус опорного)

## 📡 4. Датчики расстояния (7 штук)

### Что измерить:
Для КАЖДОГО из 7 датчиков:
- [ ] **Позиция X** (вперед/назад от центра): ___ см
- [ ] **Позиция Y** (влево/вправо от центра): ___ см
- [ ] **Позиция Z** (высота от земли): ___ см
- [ ] **Угол поворота** (в какую сторону смотрит): ___ градусов

### Схема расположения датчиков:
```
     sensor_front_left   sensor_front_center   sensor_front_right
            ↖                   ↑                    ↗
              \                 |                  /
               \                |                 /
                +---------------+---------------+
sensor_left  ← | |             | |             | | → sensor_right
                +---------------+---------------+
               /                |                 \
              /                 |                  \
            ↙                   ↓                    ↘
    sensor_back_left      (задний центр?)      sensor_back_right
```

### Где в URDF:
```xml
<!-- Строки ~243, ~267, ~291, ~315, ~339, ~363, ~387 -->

<!-- Пример для переднего центрального датчика -->
<origin xyz="0.16 0 0.08" rpy="0 0 0"/>
<!--         ^^^^  ^  ^^^^      ^
           X    Y  Z          Yaw (поворот) -->
```

### Текущие значения (примерные):

| Датчик | X (м) | Y (м) | Z (м) | Yaw (рад) | Направление |
|--------|-------|-------|-------|-----------|-------------|
| front_center | 0.16 | 0.00 | 0.08 | 0.0 | Вперед |
| front_left | 0.14 | 0.08 | 0.08 | 0.52 | Вперед-влево (30°) |
| front_right | 0.14 | -0.08 | 0.08 | -0.52 | Вперед-вправо (-30°) |
| left | 0.00 | 0.11 | 0.08 | 1.57 | Влево (90°) |
| right | 0.00 | -0.11 | 0.08 | -1.57 | Вправо (-90°) |
| back_left | -0.14 | 0.08 | 0.08 | 2.62 | Назад-влево (150°) |
| back_right | -0.14 | -0.08 | 0.08 | -2.62 | Назад-вправо (-150°) |

### Углы в радианах:
- 0° = 0.0 рад (вперед)
- 30° = 0.52 рад
- 90° = 1.57 рад (влево)
- 150° = 2.62 рад
- 180° = 3.14 рад (назад)

### Как измерить:
1. **Позиция**: Измерить расстояние от центра робота до датчика
   - X: положительное = вперед, отрицательное = назад
   - Y: положительное = влево, отрицательное = вправо
   - Z: высота от земли

2. **Угол**: В какую сторону "смотрит" датчик
   - Транспортиром или визуально определить направление
   - Перевести в радианы: `радианы = градусы × 3.14159 / 180`

## 🛠️ Как применить измерения

### Шаг 1: Запишите измерения
Заполните все пункты выше реальными значениями.

### Шаг 2: Откройте URDF файл
```bash
cd /путь/к/verter-robot/verter_admin
nano src/verter_admin/urdf/verter_robot.urdf
```

### Шаг 3: Найдите и замените значения
Ищите комментарии `<!-- TODO: ИЗМЕРИТЬ И ЗАМЕНИТЬ НА РЕАЛЬНЫЕ ЗНАЧЕНИЯ -->`

### Шаг 4: Пересоберите пакет
```bash
colcon build --packages-select verter_admin --symlink-install
```

### Шаг 5: Проверьте в RViz
```bash
# Терминал 1: Запуск robot_state_publisher
ros2 launch verter_admin robot_description.launch.py

# Терминал 2: Запуск RViz
rviz2
```

В RViz:
1. Add → RobotModel
2. Fixed Frame: `base_link`
3. Add → TF (чтобы видеть все координатные системы)

Проверьте что робот выглядит правильно!
