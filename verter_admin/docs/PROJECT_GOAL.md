# Цель проекта Verter Robot

## Основная миссия

Создать автономного мобильного робота для навигации в крупных помещениях (больницы, торговые центры), способного:

1. **Автоматически сканировать и картографировать помещение** с использованием лидара
2. **Составлять точную карту** окружающего пространства
3. **Автономно перемещаться** по составленной карте
4. **Навигировать к заданным точкам (waypoints)** по команде пользователя
5. **Избегать препятствий** в динамической среде

## Целевые помещения

- Больницы (коридоры, палаты, холлы)
- Торговые центры (широкие проходы, большие площади)
- Офисные здания
- Складские помещения

**Характеристики:**
- Площадь: от 500 м² до нескольких тысяч м²
- Динамические препятствия (люди, тележки)
- Разнообразная геометрия помещений

## Ключевые требования

### Функциональные

1. **SLAM (Simultaneous Localization and Mapping)**
   - Построение 2D карты помещения в реальном времени
   - Точность локализации: ±10 см
   - Качество карты: высокое (четкие контуры стен, препятствий)

2. **Автономная навигация**
   - Планирование пути без столкновений
   - Объезд динамических препятствий
   - Восстановление при потере пути

3. **Автономное исследование (Exploration)**
   - Самостоятельное исследование неизвестных областей
   - Полное покрытие доступного пространства
   - Оптимизация маршрута исследования

4. **Управление через GUI**
   - Визуализация карты в реальном времени
   - Установка waypoints кликом по карте
   - Сохранение/загрузка наборов waypoints
   - Мониторинг состояния робота

5. **Голосовое управление** (уже реализовано)
   - Команды перемещения
   - Интеграция с AI ассистентом

### Технические

1. **Сенсорная система**
   - **Основной:** RPLiDAR A1M8 (180° FOV спереди, дальность 12м)
   - **Дополнительные:** 7 ультразвуковых датчиков HC-SR04 (~150° спереди, от -76° до +76°)
   - **Локализация:** IMU MPU-6050 + энкодеры колес
   - **Вычислитель:** NVIDIA Jetson Orin Nano (CUDA-accelerated processing)

2. **Программная платформа**
   - ROS2 Humble
   - Nav2 navigation stack
   - SLAM Toolbox
   - Gazebo для симуляции

3. **Производительность**
   - Скорость движения: до 0.3 м/с
   - Частота обновления карты: 5-10 Hz
   - Время реакции на препятствие: <500 мс

## Технические ограничения

### Сенсорное покрытие
- **Лидар:** RPLiDAR A1M8 - 180° FOV (только передняя полусфера)
- **Ультразвуковые:** 7 датчиков HC-SR04 - покрытие ~150° спереди (от -76° до +76°)
- **Слепая зона:** Задняя часть робота (~180°) не имеет сенсорного покрытия
- **Стратегия митигации:**
  - Движение преимущественно вперед (дифференциальный привод)
  - Повороты на месте перед движением задним ходом
  - Планирование путей Nav2 с минимизацией движения назад
  - Использование одометрии и IMU для контроля задней зоны
  - Возможность добавления заднего ультразвукового датчика при необходимости

### Вычислительная мощность
- **Целевая платформа:** NVIDIA Jetson Orin Nano
  - GPU: 1024-core NVIDIA Ampere GPU с 32 Tensor Cores
  - CPU: 6-core Arm Cortex-A78AE
  - Память: 8GB LPDDR5
  - AI Performance: 40 TOPS (INT8)
- **Преимущества:**
  - CUDA ускорение для обработки laser scans
  - Возможность GPU-accelerated SLAM (CUDA-accelerated scan matching)
  - Быстрая обработка costmaps
  - Потенциал для computer vision задач в будущем
  - Запас производительности для дополнительных функций

### Окружающая среда
- Прозрачные поверхности (стекло) - ограниченная детекция
- Зеркальные поверхности - возможны артефакты на карте
- Высокая плотность людей - требуется robust obstacle avoidance

## Критерии успеха

1. Робот автономно строит карту помещения площадью 1000+ м² за 20-30 минут
2. Навигация к waypoint с точностью ±15 см
3. Время безотказной работы: 2+ часа
4. Оператор может установить маршрут из 10+ waypoints за 2-3 минуты
5. Успешное избегание 95%+ динамических препятствий
