# Установка проекта (с нуля на Ubuntu 22.04)

## Порядок установки

| Шаг | Описание | Примерное время |
|---|---|---|
| [1. Настройка Ubuntu + ROS2](os_setup.md) | Локаль, репозиторий ROS2, установка Humble, dev-tools | 15–20 мин |
| [2. Настройка udev правил](udev_rules.md) | Постоянные имена для лидара и Arduino | 5–10 мин |
| [3. Сборка проекта](project_build.md) | Клонирование, colcon, Python-зависимости | 5–10 мин |

## Системные требования

- **ОС**: Ubuntu 22.04
- **ROS2**: Humble
- **Python**: 3.10 (встроенная в ROS2 Humble)
- **Аудио**: PulseAudio / PipeWire
- **Железо**:
  - NVIDIA Jetson Orin Nano или x86-совместимый компьютер
  - RPLiDAR A1M8
  - Arduino (шасси, сенсоры, голова — опционально)
  - Микрофон (ReSpeaker USB Array) и динамик/наушники
