# Обзор проекта Verter Robot

## Миссия

Создать автономного мобильного робота для навигации в крупных помещениях, способного автоматически строить карты, перемещаться по waypoint-точкам и управлять голосом с интеграцией AI-ассистента.

## Целевые среды

- Больницы (коридоры, палаты, холлы)
- Торговые центры (широкие проходы, большие площади)
- Офисные здания
- Складские помещения

**Характеристики сред:** площадь от 500 м2 до нескольких тысяч м2, динамические препятствия (люди, тележки), разнообразная геометрия помещений.

## Функциональные требования

1. **SLAM** -- построение 2D-карты в реальном времени, точность локализации плюс-минус 10 см, высокое качество контуров стен и препятствий.

2. **Автономная навигация** -- планирование пути без столкновений, объезд динамических препятствий, восстановление при потере пути.

3. **Автономное исследование** -- самостоятельное покрытие неизвестных областей, оптимизация маршрута.

4. **Управление через веб-GUI** -- визуализация карты, установка waypoint кликом, сохранение и загрузка наборов точек, мониторинг состояния.

5. **Голосовое управление** -- команды перемещения, интеграция с AI-ассистентом (YandexGPT), синтез речи для ответов.

## Критерии успеха

1. Автономное построение карты помещения площадью 1000+ м2 за 20-30 минут.
2. Навигация к waypoint с точностью плюс-минус 15 см.
3. Время безотказной работы -- 2+ часа.
4. Установка маршрута из 10+ waypoint за 2-3 минуты оператором.
5. Успешное избегание 95%+ динамических препятствий.

## Аппаратная конфигурация

| Компонент | Модель | Назначение |
|-----------|--------|------------|
| Вычислитель | NVIDIA Jetson Orin Nano Super 8GB | ROS2, SLAM, навигация, AI |
| Лидар | RPLiDAR A1M8 | 2D-сканирование, 180 градусов FOV, дальность 12 м |
| Ультразвук | 7 x HC-SR04 | Дистанционное обнаружение (~150 градусов спереди) |
| IMU | MPU-6050 | Инерциальная локализация |
| Микрофон | ReSpeaker USB с DOA | Распознавание речи, определение направления |
| Контроллер шасси | ESP32 с micro-ROS | Управление моторами, связь с Jetson |

## Программная платформа

- **ROS2 Humble** -- основная робототехническая платформа
- **Nav2** -- навигационный стек (планирование, локализация, avoidance)
- **SLAM Toolbox** -- построение карт
- **Sherpa-ONNX** -- распознавание речи (STT)
- **Piper / Silero** -- синтез речи (TTS)
- **YandexGPT** -- AI-ассистент для обработки вопросов
- **React + TypeScript** -- веб-интерфейс управления waypoint

## Производительность

- Скорость движения: до 0.3 м/с
- Частота обновления карты: 5-10 Гц
- Время реакции на препятствие: менее 500 мс
