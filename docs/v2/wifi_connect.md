# Подключение робота к WiFi

Робот использует **balena wifi-connect** — captive portal для настройки WiFi без монитора и клавиатуры.

## Как это работает

1. Робот загружается и проверяет, подключён ли уже к WiFi (`iwgetid`)
2. Если WiFi не подключён — **создаёт свою точку доступа** с SSID `Verter-Setup`
3. Вы подключаетесь к ней с ноутбука/телефона
4. Открывается веб-страница с формой выбора WiFi-сети и ввода пароля
5. После подключения робот запоминает сеть и при следующей загрузке подключается к ней автоматически

## Как подключить робота к новому WiFi

### 1. Включить робота

Робот загрузится, подождёт 15 секунд (на случай если есть известная WiFi-сеть), и если не подключился — запустит точку доступа.

### 2. Подключиться к точке доступа робота

На ноутбуке или телефоне найдите в списке WiFi-сетей:

- **SSID:** `Verter-Setup`
- **Пароль:** `verter123`

### 3. Настроить WiFi через веб-интерфейс

После подключения к точке доступа:

1. Откройте браузер, перейдите по адресу: `http://192.168.42.1`
2. Должна открыться страница со списком доступных WiFi-сетей
3. Выберите свою сеть, введите пароль
4. Нажмите **Connect**

### 4. Подождать переподключения

Робот подключится к выбранной сети, точка доступа `Verter-Setup` исчезнет.

Теперь вы можете подключиться к роботу по SSH (см. [Удалённое подключение](remote_access.md)).

## Установка и настройка

Система уже предустановлена на роботе. Если потребуется переустановить вручную:

### Файлы

```
~/verter-robot/wifi-connect/
├── wifi-connect                 # Бинарник balena wifi-connect (ARM64)
├── wifi-connect.service         # Systemd-сервис
├── wifi-connect-start.sh        # Скрипт запуска
└── ui/                          # Веб-интерфейс captive portal
    ├── index.html
    └── static/
```

### Systemd-сервис

Сервис уже установлен:

```bash
sudo systemctl enable wifi-connect.service   # Включить автозапуск
sudo systemctl disable wifi-connect.service  # Отключить
sudo systemctl start wifi-connect.service    # Запустить вручную
sudo systemctl status wifi-connect.service   # Статус
```

### Конфигурация

Параметры точки доступа задаются в `/etc/systemd/system/wifi-connect.service` или в `wifi-connect-start.sh`:

| Переменная | Значение по умолчанию | Описание |
|---|---|---|
| `PORTAL_SSID` | `Verter-Setup` | Имя точки доступа |
| `PORTAL_PASSPHRASE` | `verter123` | Пароль точки доступа |
| `PORTAL_INTERFACE` | `wlP1p1s0` | WiFi-интерфейс |
| `PORTAL_GATEWAY` | `192.168.42.1` | IP-адрес шлюза |
| `PORTAL_DHCP_RANGE` | `192.168.42.2,192.168.42.254` | Диапазон DHCP |
| `ACTIVITY_TIMEOUT` | `0` (нет таймаута) | Время ожидания подключения |

### Логи

```bash
# Посмотреть последние запуски
journalctl -u wifi-connect.service -n 50 --no-pager

# Следить за логами в реальном времени
journalctl -u wifi-connect.service -f
```

## Если что-то пошло не так

- **Точка доступа не появилась** — проверьте что WiFi-адаптер включён: `nmcli radio wifi`
- **Не открывается страница** — проверьте что адрес `http://192.168.42.1` (не HTTPS)
- **Робот не подключается к WiFi после настройки** — проверьте логи: `journalctl -u wifi-connect.service -n 30`
- **Хотите сбросить WiFi** — удалите сохранённую сеть: `sudo nmcli connection delete <имя_сети>` и перезагрузитесь
