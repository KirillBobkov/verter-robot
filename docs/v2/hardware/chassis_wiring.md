# Схема подключения шасси (ZLAC8015D)

Все электрические соединения в архитектуре шасси после миграции на ZLAC8015D + хаб-моторы ZLLG80ASM250. Используется как чертёж для сборки и референс при обслуживании.

> **Отсутствие аппаратного E-stop.** Физическая кнопка E-stop не устанавливается.
> Аварийная остановка — Modbus comm-loss watchdog в драйвере + ChassisPolicy
> software watchdog + twist_mux safety priority + главный силовой выключатель.

---

                  │    │  ЛОГИЧЕСКАЯ ВЕТКА            │                              │

## 2. Электрические зоны и разделение земель

Три независимые земли, соединённые только в одной точке (star ground):

| Зона | Что в ней | Земля |
|---|---|---|
| **Силовая** | Батарея, мотор-каналы ZLAC8015D, мотор-фазы | `PGND` |
| **Сигнальная драйвера** | Hall-сенсоры, DI/DO, RS-485 на стороне ZLAC | `SGND_drv` |
| **Логическая Jetson** | Jetson, USB, USB-стороны конвертеров | `GND_logic` |

Соединения:
- `PGND` ↔ `SGND_drv` — **внутри** ZLAC8015D (драйвер связывает сам)
- `SGND_drv` ↔ `GND_logic` — **разорваны** (изоляция USB-RS485)
- `PGND` ↔ `GND_logic` — **разорваны** (изолированный DC-DC)

### Star ground

Одна точка — минусовая клемма батареи. Каждый возврат отдельным проводом. Не делать «гирлянду».

### Почему так

Импульсные токи мотор-фаз текут только по силовой петле. Сигнальные земли не несут силовой ток — нет шума на Hall/DI/RS-485. Изоляция между сигнальной и логической землёй гарантирует, что при аварии в силовой части Jetson останется жив.

## 3. Силовое питание

### 3.1 Батарея

- LiFePO4 24V. Ёмкость 20-40 Ач (2 мотора × ~5А средний + Jetson ~3А = ~13А средний)
- BMS обязателен: защита от переразряда, перезаряда, КЗ, балансировка
- Разъём: Anderson PowerPole 75A или XT60/XT90

### 3.2 Главный выключатель

- Поворотный, ≥ 50А. Между плюсом батареи и распределительной шиной
- На корпусе робота, доступен снаружи одной рукой за ≤1 секунду
- Единственный механический способ гарантированно остановить моторы

### 3.3 Предохранители

| Цепь | Номинал | Назначение |
|---|---|---|
| Главный (после выключателя) | 30-40 А | Защита от КЗ силовой шины |
| ZLAC8015D вход | 30 А | Защита драйвера и проводки |
| DC-DC к Jetson | 5 А | Логическая ветка независима |

Каждая нагрузка — отдельный предохранитель. При КЗ в моторе Jetson продолжает работать.

### 3.4 DC-DC для Jetson

- Вход: 24V, выход: 5V/4A для Jetson Nano
- Изолированный (изоляция вход↔выход). Mean Well RSDW20G-05 или эквивалент
- Запас по току ×1.5 от пикового
- Конденсаторы: 470-1000 мкФ + керамика 0.1 мкФ

### 3.5 Силовая проводка

| Цепь | Длина | Сечение | Тип |
|---|---|---|---|
| Батарея → выключатель | ≤ 0.3 м | 6 мм² | Силиконовый |
| Выключатель → шина → ZLAC | ≤ 1 м | 4 мм² | Силиконовый, крас/чёрн |
| ZLAC → мотор-колёса | ≤ 1.5 м | 2.5 мм² | Силиконовый, **витой** (3 фазы скручены) |
| Шина → DC-DC Jetson | ≤ 0.5 м | 1.5 мм² | Многожильный |

## 4. ZLAC8015D — подключение

### Раскладка разъёмов

```
┌─────────────────────────────────────────────────────────────┐
│                       ZLAC8015D                             │
│                                                             │
│  ┌─ POWER ─────────────────┐        ┌─ MOTOR 1 (LEFT) ───┐  │
│  │  V+   (+24V)            │        │  U1, V1, W1         │  │
│  │  GND  (силовая земля)   │        │  +5V, GND           │  │
│  └─────────────────────────┘        │  Ha1, Hb1, Hc1      │  │
│                                     └─────────────────────┘  │
│  ┌─ COMMUNICATION ─────────┐                                 │
│  │  RS-485 A               │        ┌─ MOTOR 2 (RIGHT) ──┐   │
│  │  RS-485 B               │        │  U2, V2, W2         │   │
│  │  GND (485 signal gnd)   │        │  +5V, GND           │   │
│  └─────────────────────────┘        │  Ha2, Hb2, Hc2      │   │
│                                     └─────────────────────┘   │
│  ┌─ I/O ─────────────────┐          (все DI — не подключены)  │
│  │  DI1-DI4  — не подключ │          DO1 — fault LED           │
│  │  DO1, DO2              │                                   │
│  └───────────────────────┘                                   │
└─────────────────────────────────────────────────────────────┘
```

### Power input

- V+ — плюс через предохранитель. GND — минус через star ground
- Электролитический конденсатор 470 мкФ × 63В на клеммы V+/GND
- Полярность критична — при обратной драйвер выходит из строя

### RS-485

- 485-A ↔ A конвертера, 485-B ↔ B конвертера
- GND signal — третий проводник в кабеле RS-485
- Терминатор 120 Ω между A и B на стороне ZLAC

### Digital Inputs

Все DI-входы **не подключены**. Управление enable только через Modbus control word (`CTRL_ENABLE = 0x0008`, `CTRL_DISABLE = 0x0007`).

> Заводская конфигурация может требовать DI1. Если `zlac_probe enable` не работает — через ServoStudio перевести DI1 в режим «not used».

### Digital Outputs

- DO1 (fault) — на индикатор fault LED (резистор 1 кОм)
- DO2 (brake) — не подключать (у ZLLG80ASM250 нет встроенного тормоза)
- Open collector, требуют pull-up

## 5. Мотор-колёса ZLLG80ASM250

### Силовой жгут (3 провода)

| Провод | Цвет | Функция | Куда |
|---|---|---|---|
| U | жёлтый | фаза U | M1: U1 (левое) / M2: U2 (правое) |
| V | зелёный | фаза V | M1: V1 / M2: V2 |
| W | синий | фаза W | M1: W1 / M2: W2 |

Цветовая маркировка зависит от партии — сверяться с биркой на проводе.

### Сигнальный жгут

| Провод | Цвет | Функция | Куда |
|---|---|---|---|
| +5V | красный | питание Hall + энкодера | ZLAC +5V |
| GND | чёрный | земля сигнальная | ZLAC GND |
| Ha | синий | Hall A | ZLAC Ha |
| Hb | зелёный | Hall B | ZLAC Hb |
| Hc | жёлтый | Hall C | ZLAC Hc |
| Ea | оранжевый | Encoder A | ZLAC encoder A |
| Eb | белый | Encoder B | ZLAC encoder B |
| Temp | серый | термистор | опционально |

> Точный состав жгута уточнить по даташиту поставки. 5-проводный (только Hall) не хватит для odometry на низких скоростях.

### Соответствие лево/право

- M1 → левое колесо, M2 → правое колесо
- Знаки: Left sign=-1, Right sign=+1 (калибровать на bench)

### Прокладка проводов

- Силовые 3 фазы — **скрутить вместе** (1 виток на 5-10 см)
- Сигнальный жгут — экранированный, экран на стороне ZLAC на signal GND (НЕ на двух сторонах)
- Сила и сигналы — разнести минимум на 5 см

## 6. RS-485 связь Jetson ↔ ZLAC8015D

```
   Jetson USB-A
        │
        │ USB-кабель ≤1м, ферритовое кольцо
   [Iso USB↔RS485 конвертер]
        │ A
        │ B
        │ GND
        │ Витая пара экранированная, ≤ 2 м
   ZLAC8015D 485: A, B, GND + терминатор 120Ω
```

- udev-правило: `/dev/zlac_chassis`
- 115200 / 8N1, slave-адрес: 1

## 7. Аварийная остановка

```
Уровень 1  ZLAC8015D Modbus comm-loss watchdog (~200 мс)
            Если Modbus не приходит → target RPM=0 автоматически

Уровень 2  ChassisPolicy software watchdog (500 мс)
            /cmd_vel не приходит → ACTIVE→SAFE_STOP, WheelTargets.zero()

Уровень 3  twist_mux SAFETY_CMD_VEL (priority=200)
            proximity_safety_node публикует стоп

Уровень 4  Главный силовой выключатель (механический)
            Полное обесточивание мотор-каналов
```

### Восстановление

| Сценарий | Восстановление |
|---|---|
| Comm-loss watchdog | Автоматически при возобновлении Modbus |
| Software watchdog | Новый `/cmd_vel` → автоматический переход в ACTIVE |
| Драйвер fault | Убрать причину → lifecycle cleanup → configure → activate |
| Главный выключатель | Вернуть выключатель → перезапустить lifecycle |

## 10. Порядок сборки

1. **Крепление компонентов** — ZLAC8015D, DC-DC, выключатель, предохранители. Без батареи.
2. **Сигнальная разводка** — RS-485, USB. Перед силовой.
3. **Силовая разводка** — провода проведены, батарея не подключена.
4. **Тест мультиметром (без питания):**
   - V+ ↔ GND на ZLAC > 1 кОм (без КЗ)
   - Прозвон RS-485: A↔A, B↔B, без перекрещиваний
   - Прозвон мотор-фаз: U↔U, V↔V, W↔W
5. **Подключить мотор-колёса** — силовые + сигнальные жгуты.
6. **Bench-тест RS-485** — Jetson читает версию ZLAC. Силовой выключатель ВЫКЛ.
7. **Подача силы** — выключатель ON. Ток покоя < 0.5 А.
8. **Тест моторов (колёса в воздухе)** — +50 RPM, проверить направление.
9. **Тест на полу** — прямой путь, поворот, калибровка 1.0 м.

## 11. Включение / выключение

### Включение
1. Главный выключатель → ON
2. Jetson загружается (~30 сек)
3. ROS2 стек, `zlac_chassis_node`: unconfigured → inactive → active

### Штатное выключение
1. Стоп миссии в ROS2
2. `zlac_chassis_node` → deactivate
3. `sudo shutdown -h now`
4. Главный выключатель → OFF

### Аварийная остановка
1. Софт: стоп в `/safety/cmd_vel` (priority 200), или `ros2 lifecycle set /zlac_chassis_node deactivate`
2. Механика: главный выключатель → OFF

## 12. Чек-лист валидации

### Перед первым включением (мультиметр)
- [ ] Полярность батареи: + к плюсу, − к минусу
- [ ] Выключатель размыкает плюсовую линию
- [ ] V+ ↔ GND на ZLAC > 1 кОм
- [ ] RS-485: A↔A, B↔B
- [ ] Мотор-фазы: U↔U, V↔V, W↔W
- [ ] Земли в звезду, не в гирлянду
- [ ] Экраны мотор-сигналов — на GND только на стороне ZLAC

### После включения (без моторов)
- [ ] Ток покоя ZLAC < 0.5 А
- [ ] LED: power ON, нет fault
- [ ] `/dev/zlac_chassis` существует
- [ ] Modbus: версия прошивки, fault = 0

### Моторы в воздухе
- [ ] +50 RPM M1 → левое вперёд
- [ ] +50 RPM M2 → правое вперёд
- [ ] -50 RPM → реверс
- [ ] Снятие USB-RS485 → остановка через comm-loss ≤ 500 мс
- [ ] Выключатель OFF → тормоз мгновенно

### На полу
- [ ] Прямой путь без проскальзывания
- [ ] Поворот на месте → колёса в противоположных направлениях
- [ ] 1.0 м → энкодер фиксирует ожидаемое число импульсов

## 13. Что не изменилось

- Прошивка `firmware/esp32_chassis/`

- udev-правило `/dev/esp32_chassis`
- Один micro-ROS Agent (оставить только для IMU)
