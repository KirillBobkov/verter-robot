# Голосовое управление

## Триггерные слова

Система распознавания речи активируется при произнесении триггерного слова в начале фразы. Варианты:

- **робот**
- **вертер**
- **вектор**

После триггера система переходит в активный режим прослушивания и ожидает команду или вопрос.

## Команды движения

Команды движения обрабатываются приоритетно -- до передачи запроса в AI-ассистента:

| Команда | Действие |
|---------|----------|
| **вперед** | Движение вперед |
| **назад** | Движение назад |
| **влево** | Поворот/движение влево |
| **вправо** | Поворот/движение вправо |
| **стоп** | Остановка движения |

## Завершение диалога

Стоп-слова завершают активный диалог и сбрасывают состояние системы:

- **хватит**
- **спасибо**
- **пока**
- **до свидания**

## Архитектура голосового конвейера

Система построена как конвейер из ROS2-нод:

```
Микрофон
  |
  v
[STT: sherpa-onnx] -- распознавание речи --> recognized_text
  |
  v
[Recognition node] -- конечный автомат, маршрутизация
  |
  +---> verter_commands  (команды движения --> шасси)
  +---> ai_question      (вопросы --> AI)
  |
  v
[AI Assistant: YandexGPT] --> text_to_speech
  |
  v
[TTS: Piper/Silero] --> озвучивание + tts_control
  |
  v
[Sound Player] --> звуковые эффекты
```

### Этапы обработки

1. **STT** (`speech_to_text_node`) слушает микрофон через Sherpa-ONNX, публикует распознанный текст в `recognized_text`.
2. **Recognition** (`recognition_node`) принимает текст, определяет тип команды по состояниям и таймерам:
   - Команда движения -> публикует `verter_commands`
   - Вопрос к AI -> публикует `ai_question`
   - Стоп-слово -> завершает диалог
3. **AI** (`ai_assistant_node`) обрабатывает вопросы через YandexGPT, публикует ответ в `text_to_speech`.
4. **TTS** (`text_to_speech_node`) озвучивает текст. Во время воспроизведения публикует `tts_control=false`, что глушит STT и recognition.
5. **Sound Player** (`sound_player_node`) воспроизводит короткие звуковые эффекты по топику `play`.

## Карта ROS2-топиков

| Топик | Тип | Производитель | Потребитель | Назначение |
|-------|-----|---------------|-------------|------------|
| `recognized_text` | String | STT node | Recognition | Распознанная фраза (сырой текст) |
| `speech_control` | Bool | Recognition | STT node | Вкл/выкл прослушивание STT |
| `tts_control` | Bool | TTS node | STT + Recognition | Мьют системы на время озвучки |
| `ai_question` | String | Recognition | AI Assistant | Очищенный вопрос для AI (без триггера) |
| `text_to_speech` | String | AI + Recognition | TTS node | Фраза для озвучивания |
| `play` | String | Recognition + AI | Sound Player | Имя звукового файла или `stop_sound` |
| `verter_commands` | String | Recognition | Chassis (Arduino) | Команды формата `CHASSIS:*` |
| `/cmd_vel` | Twist | Nav2 | Chassis | Команды скорости от навигации |
| `head_commands` | String | Внешние команды | DOA node (Arduino) | Управление головой робота |
| `doa_active` | Bool | -- | DOA node | Вкл/выкл определения направления речи |

## Мьют STT во время воспроизведения речи

Когда TTS-нода озвучивает ответ, она публикует `tts_control=false`. Этот сигнал поступает одновременно на STT-ноду и recognition-ноду, временно отключая прослушивание микрофона. Это предотвращает ложное распознавание собственного голоса робота как пользовательской команды.

После завершения воспроизведения TTS публикует `tts_control=true`, и система возвращается в режим прослушивания.
