# Внешние зависимости проекта

Рабочий корень — `/home/jetson/verter-robot`. Исходники, модели, карты и зависимости
приложения находятся внутри него, но запуск требует окружения ОС и пользователя.
Удалять всё остальное из `/home/jetson` нельзя.

## Файлы окружения

| Путь | Назначение |
|---|---|
| `~/.config/systemd/user/` | Установленные units Verter и ссылки автозапуска |
| `~/.bashrc` | Подключение `verter-robot/tools/env.sh` для терминала |
| `~/.profile`, `~/.xsession`, `~/.xsessionrc`, `~/.Xauthority` | Пользовательский/графический сеанс; важны для локального экрана |
| `~/.config`, `~/.local/share`, `~/.mozilla`, `~/snap` | Настройки и данные программ; целиком не удалять как файлы проекта |
| `~/.ssh`, `~/.gnupg`, `~/.gitconfig`, `~/.vnc` | Доступ, ключи, Git и удалённый рабочий стол |
| `/etc/udev/rules.d/` | Разрешения камеры и постоянные имена последовательных устройств |
| `/etc/systemd/system/wifi-connect.service` | Системный запуск настройки Wi-Fi, если установлен |
| `/var/lib/systemd/linger/jetson` | Сохранение пользовательского менеджера systemd без SSH-сеанса |

Работа также зависит от `/opt/ros/humble`, системных Python/библиотек, NVIDIA
JetPack, BlueZ, NetworkManager, systemd, SSH, звукового и графического стека.
Эти зависимости разворачиваются установкой системы, а не одним Git clone.

## Где находятся зависимости приложения

| Компонент | Путь внутри проекта |
|---|---|
| Python ROS-нод | `.python/site` (`PYTHONNOUSERSITE=1`) |
| Python отдельных служб | `.venv-nats`, `.venv-bms-ble`, `.venv-camera` |
| micro-ROS Agent | `vendor/microros_ws` |
| PlatformIO | `vendor/platformio` |
| Голосовые модели | `assets/` |
| Карты и состояние | `data/` |
| Кеши и профиль kiosk | `data/cache`, `data/kiosk-profile` |
| Логи ROS и supervisor | `run/` |

Соседние `ros2_ws`, `microros_ws`, `esp32-debug`, `verter-retired-firmware-20260917`,
`maps` и `dtest_map.*` не являются источниками штатного запуска. Это не разрешение
удалять чужие данные или общие настройки. `.platformio`, `.ros`, `.rviz2`, `.cache`,
`.npm` могут использоваться интерактивными инструментами даже при отсутствии
зависимости работающих служб Verter. Удаление оценивают для конкретных путей.

Для проверки внешних связей после изменения установки проверяют unit-файлы,
символические ссылки, окружение процессов, Python import paths, ELF RPATH,
открытые файлы `/proc/<pid>/fd` и библиотеки `/proc/<pid>/maps`. Один поиск строк
с путями не доказывает отсутствие зависимости. `archive/` не используется при запуске.
