# `doa_node`

## Задача

DOA = *direction of arrival* (направление, откуда пришёл звук).

Нода периодически читает угол DOA с ReSpeaker USB Array и на основе этого отправляет команды поворота “головы” в Arduino (отдельная плата для головы/глаз).

## Входы / выходы

- **Sub**: `head_commands` (String) — внешние команды головы (override)
- **Sub**: `doa_active` (Bool) — включить/выключить DOA-реакцию

## Простыми словами

- Если DOA включен, раз в `DOA_POLLING_INTERVAL` секунд читает `DOAANGLE`.
- Конвертит диапазоны углов в команды `HEAD:CENTER | HEAD:LEFT | HEAD:RIGHT`.
- Дебаунсит одинаковые команды подряд (не шлёт повтор).
- Шлёт команду по serial в Arduino головы.
