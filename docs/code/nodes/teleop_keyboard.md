# `teleop_keyboard`

## Задача

Ручное управление роботом с клавиатуры: публикует `cmd_vel` (Twist), который дальше может потреблять `chassis_node` и/или Nav2.

## Входы / выходы

- **Pub**: `cmd_vel` (Twist)

## Управление

- `w/↑` — вперёд
- `s/↓` — назад
- `a/←` — поворот влево
- `d/→` — поворот вправо
- `space` — стоп
- `+/-` — изменить скорость
- `q` — выход
