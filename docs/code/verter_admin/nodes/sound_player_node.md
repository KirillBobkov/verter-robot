# `sound_player_node`

## Задача

Играет короткие звуки по команде из топика `play`.

## Входы / выходы

- **Sub**: `play` (String)

## Команды

- `stop_sound` — убить текущий звук и принудительно остановить аудио-процессы
- иначе — имя файла в каталоге `sounds` пакета:
  - если расширения нет → добавляется `.wav`
  - `.wav` играет напрямую через `aplay`
  - `.mp3/.ogg` конвертит через `ffmpeg` в wav-поток и кормит `aplay`

## Параметры

- `audio_device` (string, default `pulse`)
