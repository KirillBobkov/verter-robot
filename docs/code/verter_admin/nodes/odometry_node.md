# `odometry_node`

## Задача

Считает “где робот находится” по командам скорости `/cmd_vel`, публикует одометрию и TF.

**Важно**: это не управление моторами. Это чистая математика/интеграция.

## Входы / выходы

- **Sub**: `/cmd_vel` (Twist)
- **Pub**: `/odom` (nav_msgs/Odometry)
- **TF**: `odom -> base_link`

## Простыми словами

- Берёт текущую скорость (vx, vth)
- Интегрирует по времени \(x += vx * dt\), \(theta += vth * dt\)
- Публикует `/odom` и трансформацию `odom -> base_link`, чтобы Nav2 работал
