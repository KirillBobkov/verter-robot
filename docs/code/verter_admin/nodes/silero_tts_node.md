# `silero_tts_node`

## Задача

Альтернативный TTS-движок (вместо Piper): озвучивает `text_to_speech`.

## Входы / выходы (ожидаемо)

- **Sub**: `text_to_speech` (String)
- **Pub**: `tts_control` (Bool) — чтобы глушить распознавание на время озвучки

## Когда выбирать

- Если Piper не устраивает качеством/скоростью на текущем железе.
- Если хочется другой голос/настройки (Silero обычно гибче).
