# Голосовое управление

## Триггер

Система ждёт “триггерные слова” в начале фразы (варианты типа “робот/вертер/вектор/…”).

## Команды движения

Движение обрабатывается приоритетно (до AI):

- “вперед”
- “назад”
- “влево”
- “вправо”
- “стоп”

## Завершение диалога

Стоп-слова типа “хватит/спасибо/пока/до свидания” завершают активный диалог и сбрасывают состояние.
