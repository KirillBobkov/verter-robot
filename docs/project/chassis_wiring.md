# Полная схема подключения шасси (ZLAC8015D)

Документ описывает все электрические соединения в новой архитектуре шасси робота Verter после миграции с ESP32 + Cytron MD10C на ZLAC8015D + хаб-моторы ZLLG80ASM250. Используется как чертёж для сборки и как референс при обслуживании.

> **Связанные документы:**
> - `usb_rs485_converter.md` — детальная спецификация на изолированный USB↔RS-485 конвертер.
> - `hardware_spec.md` — общая хардварная спецификация робота.
> - `../weels/` — скриншоты даташитов ZLAC8015D и мотор-колёс.
> - `chassis_migration_plan.md` (TBD) — общий план миграции.

## 2. Электрические зоны и разделение земель

В системе **три независимые «земли»**, которые соединяются только в одной точке (star ground):

| Зона | Что в ней | Земля называется |
|---|---|---|
| **Силовая** | Батарея, мотор-каналы ZLAC8015D, мотор-фазы | `PGND` (power ground) |
| **Сигнальная драйвера** | Hall-сенсоры моторов, DI/DO, RS-485 на стороне ZLAC | `SGND_drv` (signal ground driver) |
| **Логическая Jetson** | Jetson, USB, USB-стороны изолированных конвертеров | `GND_logic` |

Соединения:
- `PGND` ↔ `SGND_drv` — **внутри** ZLAC8015D (через короткую цепь, силовую и сигнальную земли драйвер связывает сам).
- `SGND_drv` ↔ `GND_logic` — **разорваны** благодаря изолированному USB-RS485 конвертеру (это его главная функция).
- `PGND` ↔ `GND_logic` — **разорваны** через изолированный DC-DC, который питает Jetson от батареи.

### Star ground (центральная точка)
- Одна точка соединения **PGND** на минусовой клемме батареи.
- К этой точке идут отдельные провода от:
  - Минуса основного предохранителя (возврат мотор-токов).
  - Минуса DC-DC питания Jetson.
  - (Минус BMS, если внешний.)
- **Не делать «гирлянду»** — каждый возврат отдельным проводом до батареи.

### Почему так
- Большие импульсные токи мотор-фаз (десятки ампер с фронтом мкс) текут только по силовой петле «батарея → драйвер → мотор → батарея».
- Сигнальные земли никогда не несут силовой ток → нет падения напряжения на сигнальной земле → нет шума на Hall/DI/RS-485.
- Изоляция между сигнальной и логической землёй гарантирует, что если в силовой части произойдёт авария (КЗ, бросок), Jetson останется живой.

## 3. Силовое питание

### 3.1 Батарея
- **Тип:** LiFePO4 (или Li-Ion) на номинальное напряжение мотора. **Уточнить по даташиту ZLLG80ASM250** — обычно 24V (8s LiFePO4) или 48V (13s Li-Ion).
- **Ёмкость:** считать от среднего тока × желаемое время автономной работы. Для Verter: 2 мотора × ~5А средний + Jetson ~3А → ≥ 13А средний → батарея 20–40 Ач при 24В.
- **BMS:** обязателен. Защита от переразряда, перезаряда, КЗ, балансировка. Встроенный в батарейный пак или отдельный.
- **Разъём:** Anderson PowerPole 75A или XT60/XT90, с защитой от обратной полярности.

### 3.2 Главный выключатель
- Поворотный или ключ-выключатель на номинальный ток батареи (≥ 50А).
- Стоит между плюсом батареи и распределительной шиной.
- На корпусе робота, доступен снаружи.
- Это **НЕ E-stop** — это «полное обесточивание для сервиса». E-stop (см. §7) гасит только моторы, оставляет Jetson работать.

### 3.3 Предохранители
| Цепь | Номинал | Тип | Назначение |
|---|---|---|---|
| Главный (после выключателя) | 30–40 А | Plug-in (автомобильный) или автомат | Защита от КЗ силовой шины |
| ZLAC8015D вход | 30 А | В отдельном держателе | Защита драйвера и проводки до драйвера |
| DC-DC к Jetson | 5 А | Отдельный | Логическая ветка независима от силовой |

**Правило:** каждая независимая нагрузка — отдельный предохранитель. Если КЗ в моторе — Jetson продолжает работать и может корректно остановить миссию.

### 3.4 DC-DC для Jetson
- **Вход:** напряжение батареи (24V или 48V).
- **Выход:** соответствующий Jetson (обычно 5V/4A для Nano, 19V для Orin AGX, 12V для Orin NX через адаптер).
- **Тип:** изолированный (изоляция вход↔выход) — это вторая линия гальванического разрыва между силой и логикой. Например, Mean Well RSDW20G-05 или модуль на B0524 с дополнительным фильтром.
- **Запас по току:** ×1.5 от пикового потребления Jetson.
- **На входе и выходе:** электролитические конденсаторы 470–1000 мкФ + керамика 0.1 мкФ для подавления выбросов.

### 3.5 Силовая проводка (сечения)
| Цепь | Длина | Сечение | Тип кабеля |
|---|---|---|---|
| Батарея → главный выключатель | ≤ 0.3 м | 6 мм² (AWG10) | Силиконовый многожильный |
| Выключатель → шина → ZLAC8015D | ≤ 1 м | 4 мм² (AWG12) | Силиконовый многожильный, красный/чёрный |
| ZLAC8015D → мотор-колёса | ≤ 1.5 м | 2.5 мм² (AWG14) | Силиконовый, **витой** (3 фазы скрученные между собой — снижает излучаемые помехи) |
| Шина → DC-DC Jetson | ≤ 0.5 м | 1.5 мм² (AWG16) | Любой многожильный |
| DC-DC → Jetson | ≤ 0.3 м | штатный кабель Jetson | — |

## 4. ZLAC8015D — pinout и подключение

> **ВАЖНО:** точная схема выводов и нумерация зависят от ревизии прошивки ZLAC8015D и должны быть сверены с **поставленным мануалом производителя**. Ниже — типовая схема для серии ZLAC8015D от ZLTECH; используется как чертёж для разводки, но **до первой подачи питания свериться с физическими этикетками на корпусе драйвера и таблицей в мануале**.

### 4.1 Общая раскладка разъёмов (типовая)

ZLAC8015D — корпус с тремя группами клемм:

```
┌─────────────────────────────────────────────────────────────┐
│                       ZLAC8015D                             │
│                                                             │
│  ┌─ POWER ─────────────────┐        ┌─ MOTOR 1 (LEFT) ───┐  │
│  │  V+   (+24/48V)         │        │  U1  (фаза)         │  │
│  │  GND  (силовая земля)   │        │  V1  (фаза)         │  │
│  └─────────────────────────┘        │  W1  (фаза)         │  │
│                                     │  +5V (питание Hall) │  │
│  ┌─ COMMUNICATION ─────────┐        │  GND (земля Hall)   │  │
│  │  RS-485 A               │        │  Ha1, Hb1, Hc1      │  │
│  │  RS-485 B               │        └─────────────────────┘  │
│  │  GND (485 signal gnd)   │                                 │
│  └─────────────────────────┘        ┌─ MOTOR 2 (RIGHT) ──┐   │
│                                     │  U2, V2, W2         │  │
│  ┌─ I/O ─────────────────┐          │  +5V, GND           │  │
│  │  DI1  servo enable    │          │  Ha2, Hb2, Hc2      │  │
│  │  DI2  emergency / brk │          └─────────────────────┘  │
│  │  DI3  spare           │                                   │
│  │  DI4  spare           │                                   │
│  │  DO1  fault output    │                                   │
│  │  DO2  brake output    │                                   │
│  │  COM (DI/DO common)   │                                   │
│  └───────────────────────┘                                   │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 Power input
- **V+** — плюс батареи через силовой предохранитель.
- **GND** — минус батареи (через звезду, см. §2).
- Желательно установить **электролитический конденсатор** 470 мкФ × 63В прямо на клеммы V+/GND драйвера для подавления выбросов при коммутации мотор-фаз. Большинство ZLAC уже имеют внутри, но внешний не повредит.
- **Полярность критична** — при обратной полярности драйвер выходит из строя. Перед первым включением проверить мультиметром.

### 4.3 RS-485
- **485-A** ↔ A конвертера (см. `usb_rs485_converter.md`).
- **485-B** ↔ B конвертера.
- **GND** (signal) ↔ GND signal конвертера. Третий проводник в кабеле RS-485 — желательно протянуть.
- Терминатор 120 Ω между A и B на стороне ZLAC8015D — включить (DIP/перемычка) или припаять резистор.

### 4.4 Digital Inputs (DI)

> Назначение DI программируется через Modbus-регистры. Конкретные функции каждого DI задаются при пуско-наладке. Ниже — рекомендуемая конфигурация для нашего use-case.

| Pin | Назначение | Логика | Куда подключается |
|---|---|---|---|
| DI1 | **Servo enable** (общий enable обоих моторов) | Active high (включён, когда подано питание DI) | E-stop circuit (см. §7) |
| DI2 | **Emergency stop** (резерв, активная остановка) | Active high → драйвер тормозит | Опционально — второй контакт E-stop |
| DI3 | (резерв) | — | Не подключать |
| DI4 | (резерв) | — | Не подключать |
| COM | Общий для DI (24V или 5V опорное) | — | На источник опорного напряжения через E-stop |

**Логика DI:** в большинстве ZLAC8015D DI работают как **opto-isolated входы**, активируются при наличии напряжения 12–24V между DI и COM. Точную логику (active high/low) и опорное напряжение проверить по мануалу — некоторые ревизии работают на 5V логику.

### 4.5 Digital Outputs (DO)
- **DO1 (fault)** — на индикатор «fault LED» (через резистор 1 кОм + LED) и/или на GPIO Jetson через изолятор. Сигнализирует, что драйвер ушёл в защиту.
- **DO2 (brake)** — на электромеханический тормоз, если есть. У ZLLG80ASM250 встроенного тормоза обычно нет → не подключать.
- DO — open collector, требуют внешнего pull-up к опорному напряжению.

## 5. Мотор-колёса ZLLG80ASM250

Каждый мотор имеет **два жгута**, выходящих из колеса:

### 5.1 Силовой жгут (3 провода, толстые)
| Провод | Цвет (типовой) | Функция | Куда |
|---|---|---|---|
| U | жёлтый | фаза U | ZLAC M1: U1 (для левого) или M2: U2 (для правого) |
| V | зелёный | фаза V | M1: V1 / M2: V2 |
| W | синий | фаза W | M1: W1 / M2: W2 |

> **Цветовая маркировка зависит от партии**, всегда сверяться с биркой на проводе или этикеткой на колесе. В даташите производителя должно быть указано U/V/W соответствие.

**Если фазы перепутаны:**
- Если поменять две фазы местами — мотор будет вращаться в обратную сторону. Это обычно решается **изменением знака target RPM в софте**, а не перекоммутацией. НО если ещё и Hall-сенсоры подключены неверно соответственно — мотор «будет дёргаться» / не запустится / выдаст ошибку коммутации. В этом случае надо физически переподключить две фазы и одновременно поменять две Hall-линии.

### 5.2 Сигнальный жгут (обычно 8 проводов)
| Провод | Цвет (типовой) | Функция | Куда |
|---|---|---|---|
| +5V | красный | питание Hall + энкодера | ZLAC M1/M2: +5V |
| GND | чёрный | земля сигнальная | ZLAC M1/M2: GND |
| Ha | синий | Hall sensor A | ZLAC M1/M2: Ha |
| Hb | зелёный | Hall sensor B | ZLAC M1/M2: Hb |
| Hc | жёлтый | Hall sensor C | ZLAC M1/M2: Hc |
| Ea | оранжевый | Encoder A (если есть отдельный квадратурный) | ZLAC encoder input A (если есть) |
| Eb | белый | Encoder B | ZLAC encoder input B |
| Temp | серый | термистор | (опционально) ZLAC NTC input или не подключать |

> **Уточнить состав жгута по даташиту конкретной поставки.** ZLLG80ASM250 в зависимости от ревизии может комплектоваться:
> - **5-проводным** сигнальным жгутом: только Hall A/B/C + 5V + GND. Тогда обратная связь по позиции — **только из Hall-сигналов**, разрешение около 60° электрических × N полюсов = ~24-48 «тиков» на оборот мотора. Этого может **не хватить для odometry** на низких скоростях.
> - **8-проводным**: Hall + квадратурный энкодер. Разрешение 1024–4096 ppr — ОК для odometry.
>
> На скриншотах из `docs/weels/` указано «出线长度 600±50mm» (длина кабеля 600±50 мм) и «信号线端子» (сигнальный разъём) — **необходимо запросить у поставщика точную распиновку сигнального разъёма перед заказом проводки.**

### 5.3 Соответствие лево/право
- **M1 → ЛЕВОЕ колесо (motor LEFT)**.
- **M2 → ПРАВОЕ колесо (motor RIGHT)**.
- Соглашение знаков (направление вращения для движения вперёд) задаётся в Modbus-регистре (sign reverse) или в софте Jetson. Текущая memory: «Left sign=-1, Right sign=+1» — вероятнее всего, после смены драйвера знаки изменятся, перекалибровать на bench.

### 5.4 Прокладка проводов мотор-колесо ↔ ZLAC8015D
- **Силовые 3 фазы — скрутить вместе** в общий жгут (1 виток на 5–10 см). Снижает излучаемые помехи на сигнальные кабели в 5–10 раз.
- **Сигнальный жгут — экранированный**, экран на стороне ZLAC8015D на signal GND (НЕ на двух сторонах).
- **Силовой и сигнальный жгуты — НЕ параллельно вплотную**, разнести минимум на 5 см или класть перпендикулярно. Лучшее решение — силу в одной кабель-канаве, сигналы в другой.
- Длина каждого жгута до колеса ≤ 1.5 м (готовые жгуты ZLLG80ASM250 обычно 600 мм — может потребоваться удлинение через клеммник или коннектор).

## 6. RS-485 связь Jetson ↔ ZLAC8015D

Кратко (детально — в `usb_rs485_converter.md`):

```
   Jetson USB-A
        │
        │ USB-кабель ≤1м, ферритовое кольцо
        │
   [Iso USB↔RS485 конвертер]   (Waveshare USB TO RS485 (B) или эквив.)
        │ A
        │ B
        │ GND
        │
        │ Витая пара экранированная, длина ≤ 2 м
        │ Экран → SGND_drv с одной стороны (на ZLAC)
        │
   ZLAC8015D 485 клеммы:
        A ←── A
        B ←── B
        GND ←─ GND
        + терминатор 120Ω между A/B
```

- udev-правило именует порт как `/dev/zlac_chassis`.
- Параметры порта: 115200 / 8N1 (по умолчанию ZLAC; настраивается в драйвере).
- Slave-адрес ZLAC: 1 (по умолчанию; настраивается).

## 7. Цепь E-stop

### 7.1 Топология

**Fail-safe принцип:** в нормальной работе на DI1 (servo enable) подано опорное напряжение через **нормально-замкнутую (NC)** кнопку. При нажатии E-stop цепь рвётся → DI1 теряет питание → драйвер мгновенно гасит выходные транзисторы и тормозит моторы.

**Преимущество:** обрыв любого провода в цепи E-stop = моторы тормозят (как будто кнопка нажата). Это безопаснее активной логики «при нажатии подать сигнал».

```
                  +24V (от батареи через предохранитель 1A)
                       │
                       │
              ┌────────┴────────┐
              │  E-stop (NC)    │  ← нажата = разомкнута
              │  гриб 22мм      │
              └────────┬────────┘
                       │
                       ├───→ DI1 (servo enable) ZLAC8015D
                       │
                       │ (опционально, для резерва)
                       └───→ DI2 (emergency)    ZLAC8015D

                                                  COM ZLAC8015D ── 0V (SGND_drv)
```

### 7.2 Компоненты
- **Кнопка:** грибовидная, 22 мм диаметр, NC контакт, с фиксацией поворотом (twist to release). IP65. Минимум 2 контакта (1 рабочий + 1 резервный).
- **Предохранитель:** на цепи питания E-stop (1А) — защищает от КЗ.
- **Подавитель искры:** RC-цепочка (100 Ом + 100 нФ) параллельно контактам или варистор — продлевает ресурс контактов кнопки.

### 7.3 Расположение
- **Доступна снаружи робота**, на видном месте.
- **Не закрывается** при нормальной эксплуатации (не за крышкой).
- **Не возле движущихся частей** — оператор должен иметь возможность ткнуть её в любой момент.
- Дублирование: если робот большой — две кнопки в разных местах, последовательно соединённые (любая нажатая → остановка).

### 7.4 Восстановление после E-stop
1. Поворотом разблокировать кнопку.
2. ROS-узел `zlac_chassis_node` обнаруживает, что fault-флаг ZLAC сброшен (читается через Modbus).
3. Lifecycle: `deactivate` → `activate` для безопасного re-arming. Это **операция оператора** (через топик/сервис), а не автоматическое восстановление — рулбук §3.2: «Recovery from stop MUST be explicit and observable».
4. Только после явного подтверждения оператора `zlac_chassis_node` снова разрешает движение.

### 7.5 Что E-stop НЕ делает
- Не обесточивает Jetson — он продолжает работать, ROS-граф жив, можно сохранить карту/логи.
- Не отключает питание силовой шины — драйвер обесточен только по сигналу enable, силовая шина остаётся под напряжением. Для полного обесточивания — главный выключатель (см. §3.2).

## 8. USB-связи Jetson

### 8.1 Распределение USB-портов

Все периферийные устройства подключены к USB-A портам Jetson. Привязка идёт по udev-правилам, чтобы имя порта не зависело от порядка подключения.

| Symlink | VID:PID | Описание | udev-правило |
|---|---|---|---|
| `/dev/zlac_chassis` | 0403:6001 (FTDI) или 10c4:ea60 (CP210x) | Изолированный USB-RS485 → ZLAC8015D | `99-zlac.rules` (новый) |
| `/dev/esp32_imu` | 10c4:ea60 (CP210x) | ESP32 IMU (без изменений) | существующее |
| `/dev/rplidar` | 10c4:ea60 (CP210x) | RPLidar A1/A2 + патч cp210x | существующее |
| ~~`/dev/esp32_chassis`~~ | — | **УДАЛИТЬ** после миграции — больше не используется | удалить |

> Все три CP210x устройства имеют одинаковый VID:PID. Чтобы udev различал их, правила должны содержать `ATTRS{serial}=="<уникальный SN>"` — серийник снимается через `udevadm info -a -n /dev/ttyUSB0`.

### 8.2 USB-хаб

- **Не использовать USB-хаб** для основной периферии. Jetson-порты напрямую.
- Если Jetson-портов не хватает — использовать **USB 2.0 хаб с внешним питанием** (НЕ запитывать от батареи робота напрямую без DC-DC).
- Лидар, RS-485 конвертер и IMU — приоритет на прямые порты.

### 8.3 USB-кабели
- Длина ≤ 1 м.
- С ферритовыми кольцами (особенно для USB-RS485).
- Экранированные.

## 12. Порядок сборки

Жёсткий порядок, отступление чревато статическим разрядом или подачей силы на не до конца собранный узел.

1. **Корпус и крепление компонентов** — установить ZLAC8015D, DC-DC, кнопку E-stop, держатели предохранителей на корпус робота. **Без батареи и без проводов.**
2. **Сигнальная разводка** — RS-485 кабель, провода E-stop, USB-кабели. **Перед** силовой.
3. **Силовая разводка БЕЗ батареи** — провести и закрепить силовые провода, **батарея не подключена**.
4. **Тест проводки мультиметром (без питания)**:
   - Прозвонить силу: батарея(+) ↔ ZLAC V+ через выключатель и предохранитель → должно звониться при включённом выключателе.
   - Прозвонить отсутствие КЗ: V+ ↔ GND силовой → должно быть «бесконечность» (или ёмкость конденсаторов, без короткого).
   - Прозвонить E-stop: при ненажатой кнопке цепь от +24V до DI1 замкнута, при нажатой — разомкнута.
   - Прозвонить RS-485: A конвертера ↔ A драйвера, B ↔ B, без перекрещений.
5. **Подключить мотор-колёса** (силовые + сигнальные жгуты).
6. **Подключить Jetson через DC-DC**, но **не включать выключатель** — Jetson можно отдельно запитать от лабораторного БП на этом этапе для bench-теста USB-RS485.
7. **Bench-тест RS-485** (см. `usb_rs485_converter.md` §7) — Jetson читает регистр версии ZLAC. **Силовой выключатель пока ВЫКЛ** — драйверу не нужна силовая шина для ответа по RS-485, ему нужно только логическое питание (в большинстве моделей логика питается с того же V+, но просто проверь на низком токе через лабораторный БП на 24В вместо батареи).
8. **Подача силы от батареи** — включить главный выключатель, проверить, что нет искр/дыма/нагрева, проверить ток покоя (должен быть < 0.5 А).
9. **Test motor: один оборот в воздухе** через ROS-узел или ServoStudio на минимальной RPM. Проверить, что:
   - Колесо вращается в правильную сторону для «вперёд».
   - При нажатии E-stop останавливается мгновенно.
   - При снятии RS-485 (отключить USB) — останавливается через comm-loss timeout.

## 13. Порядок включения / выключения (operational)

### Включение робота
1. E-stop ОТЖАТА (повёрнута, цепь замкнута).
2. Главный выключатель → ON.
3. Jetson загружается (~30 сек).
4. ROS 2 стек поднимается, `zlac_chassis_node` lifecycle: `unconfigured` → `inactive` (open USB).
5. Оператор активирует: `zlac_chassis_node` → `active`. Драйвер enable, can drive.

### Штатное выключение
1. Стоп миссии в ROS.
2. `zlac_chassis_node` → `deactivate` → drives disabled.
3. Shutdown Jetson (`sudo shutdown -h now`).
4. Главный выключатель → OFF.

### Аварийное выключение (E-stop)
1. Нажать E-stop → моторы тормозят.
2. Jetson, ROS-граф, лидар, IMU продолжают работать → можно сохранить логи/карту.
3. Для полного обесточивания — главный выключатель OFF.

## 14. Чек-лист валидации сборки

### Перед первым включением (мультиметр)
- [ ] Полярность батарейных клемм проверена: + к плюсовой шине, − к минусовой.
- [ ] Главный выключатель размыкает плюсовую линию.
- [ ] Сопротивление V+ ↔ GND на ZLAC > 1 кОм (без КЗ; ёмкость конденсаторов сама зарядится через секунду).
- [ ] E-stop NC: контакты замкнуты в нормальном положении, разомкнуты при нажатии.
- [ ] Прозвонка RS-485: A↔A, B↔B, без перекрещиваний.
- [ ] Прозвонка мотор-фаз: U↔U, V↔V, W↔W к каждому колесу.
- [ ] Все земли соединены в звезду на батарее, не в гирлянду.
- [ ] Экраны кабелей мотор-сигналов соединены с GND только с одной стороны (на ZLAC).

### После первого включения (без моторов)
- [ ] Ток покоя ZLAC < 0.5 А при включённом enable, без команд движения.
- [ ] Светодиоды состояния ZLAC: power ON, нет fault.
- [ ] `dmesg` Jetson показывает `/dev/ttyUSB*` для USB-RS485 конвертера.
- [ ] `/dev/zlac_chassis` существует благодаря udev.
- [ ] Modbus probe читает версию прошивки ZLAC.
- [ ] Modbus probe читает fault register = 0.

### Базовый тест моторов (колёса В ВОЗДУХЕ)
- [ ] Команда target RPM = +50 на M1 → левое колесо крутится «вперёд».
- [ ] Команда target RPM = +50 на M2 → правое колесо крутится «вперёд».
- [ ] Команда target RPM = -50 → реверс.
- [ ] Чтение actual RPM соответствует target (с погрешностью ≤ 5%).
- [ ] Нажатие E-stop при движущихся колёсах → мгновенная остановка.
- [ ] Снятие USB-RS485 при движущихся колёсах → остановка через comm-loss timeout (≤ 500 мс).
- [ ] Возврат USB → драйвер автоматически восстанавливается / готов к новому activate.

### Тест на полу
- [ ] Робот едет вперёд по прямой — колёса не «подтравливают» (одно вперёд, другое назад) → знаки правильные.
- [ ] Поворот на месте → колёса крутятся в противоположных направлениях.
- [ ] Замер: проехать ровно 1.0 м → счётчик энкодера в Modbus-регистре фиксирует ожидаемое количество импульсов (используется для калибровки meters-per-count).
